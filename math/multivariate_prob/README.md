# Multivariate Probability

Mean, covariance and correlation of data sets, and a Multivariate Normal
distribution class, written with numpy only.

## Files

- `0-mean_cov.py`: `mean_cov(X)` returns the mean (1, d) and covariance (d, d)
- `1-correlation.py`: `correlation(C)` converts a covariance matrix to a correlation matrix
- `multinormal.py`: `MultiNormal` class with `mean`, `cov` and `pdf(x)`
